# Social Distortion 34 Years — Composition Source Folder

This folder holds the pilot's **data, assets, and rendered outputs**. The composition HTML itself lives at `video/index.html` (not here), because Hyperframes renders from the project root.

## Layout

| File | Purpose |
|---|---|
| `../../index.html` | The composition. What `npx hyperframes render` renders. |
| `payload.json` | Data payload (8 shows, artist meta, featured track). Generated by `build-payload.mjs`. |
| `build-payload.mjs` | Regenerates `payload.json` from the concerts archive. Run from repo root: `node video/compositions/social-distortion-34-years/build-payload.mjs` |
| `assets/social-distortion-artist.jpg` | 700×700 archival-feel artist image (Beat 2) |
| `assets/social-distortion-album.jpg` | 600×600 album art for *Social Distortion* (Beat 5) |
| `output/pilot-mechanical.mp4` | **gitignored** — regenerate with `cd video && npx hyperframes render --output compositions/social-distortion-34-years/output/pilot-mechanical.mp4 --quality draft` |

## Rationale for the split

The pilot spec (`docs/specs/future/hyperframes-poc/morperhaus-video-pilot.md`) originally specified the composition at `video/compositions/social-distortion-34-years/composition.html`. Hyperframes' convention renders from `<project-root>/index.html`, so the composition itself sits at the workspace root. The `compositions/social-distortion-34-years/` folder persists as the source-folder for payload + assets + renders, preserving the spec's intent (one folder per video).

When Template A/B/D videos are specced and built (Phase 2+), they will each get their own sibling Hyperframes project (e.g., `video-template-a/`), *or* this workspace will be refactored to multi-composition. That decision is deferred.

## Re-rendering

```bash
cd /Users/mmorper/projects/concerts/video
npx hyperframes render \
  --output compositions/social-distortion-34-years/output/pilot-mechanical.mp4 \

```

For the Phase 2 final delivery, use `--quality high --fps 30` instead of `--quality draft`.
