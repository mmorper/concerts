Connect it in three steps

Adding it once makes the archive available across every Claude client — desktop, web, and mobile.

  1. Copy the connector URL just below.
  2. In Claude, open Settings → Connectors → Add custom connector and paste the URL.
  3. Click Add, then turn it on in any chat from the + menu → Connectors. Now just ask.
concerts.morperhaus.org/mcp

Prefer Claude Desktop's config file?

Add this to your claude_desktop_config.json, then restart Claude Desktop:

{
  "mcpServers": {
    "morperhaus": {
      "type": "http",
      "url": "https://concerts.morperhaus.org/mcp"
    }
  }
}

Any AI assistant that supports remote MCP connectors works the same way — point it at the URL above.
