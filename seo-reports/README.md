# SEO Analysis Reports

This directory contains SEO analysis reports generated by the `/seo` command.

## Files

| Pattern | Description |
|---------|-------------|
| `YYYY-MM-DD-report.md` | Human-readable markdown report |
| `YYYY-MM-DD-report.html` | Standalone HTML report for sharing |
| `YYYY-MM-DD-baseline.json` | Machine-readable baseline for comparison |
| `YYYY-MM-DD-csv/` | Multi-file CSV export for spreadsheets |

### CSV Export Contents

When using `--output csv`, a directory is created containing:

- `summary.csv` — Overview and metadata
- `pages.csv` — Per-page analysis
- `insights.csv` — All detected insights
- `recommendations.csv` — Prioritized actions
- `scores.csv` — Category breakdown
- `gsc-pages.csv` — GSC page data (if available)
- `gsc-queries.csv` — GSC query data (if available)
- `ga4-pages.csv` — GA4 page data (if available)
- `ga4-traffic.csv` — GA4 traffic sources (if available)
- `backlinks.csv` — Backlink data (if available)

## Usage

```bash
# Interactive mode (guided menu)
npm run seo

# Standard analysis (CLI + markdown)
npm run seo -- --output both

# Save current state as baseline
npm run seo -- --baseline

# Compare to previous baseline
npm run seo -- --compare 2026-01-20

# Quick score check only
npm run seo -- --quick

# Export formats
npm run seo -- --output html   # Standalone HTML
npm run seo -- --output csv    # Spreadsheet export
npm run seo -- --output md     # Markdown only

# Analyze staging site
npm run seo -- --url https://staging.example.com
```
