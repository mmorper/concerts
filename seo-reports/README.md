# SEO Analysis Reports

This directory contains SEO analysis reports generated by the `/seo` command.

## Files

- `YYYY-MM-DD-report.md` - Human-readable markdown reports
- `YYYY-MM-DD-baseline.json` - Machine-readable baseline data for comparison

## Usage

```bash
# Run standard analysis
npm run seo

# Save current state as baseline
npm run seo -- --baseline

# Compare to previous baseline
npm run seo -- --compare 2026-01-20

# Analyze staging site
npm run seo -- --url https://staging.example.com
```

## Git Tracking

- **Tracked:** Baseline JSON files (`*-baseline.json`) for historical comparison
- **Ignored:** Report markdown files (`*-report.md`) to reduce repo bloat
